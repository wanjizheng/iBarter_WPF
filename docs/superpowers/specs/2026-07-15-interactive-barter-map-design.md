# 可缩放航线地图设计

## 目标

将现有以静态海图为背景、按 `Margin` 叠加岛屿和路线的地图，升级为可缩放、可平移的路线工作台；保留默认可见的岛屿、交换物与仓库细节。

## 范围

- 保留现有 `iBarterMap.png` 海图、岛屿坐标、仓库与自动路线数据。
- 鼠标滚轮以指针位置为锚点缩放；缩放范围为 65% 到 250%。
- 空白海域右键拖拽平移；岛屿上的中键添加交换行为保持不变。
- 在右上角提供放大、缩小、复位三个可发现的控件。
- 岛屿点、仓库图标、航线、方向箭头与步骤编号跟随地图等比缩放。
- 名称和交换物信息默认显示；其屏幕字号随缩放温和变化，并被限制在 11 到 16 DIP。
- 选中的路线保持最强对比；未选路线保留可读的低对比显示，而非完全透明。
- 船舱步骤与地图的既有双向选中/高亮行为必须保留。

## 架构

`MapViewport` 负责裁剪、鼠标输入和缩放/平移状态；其内部的 `Grid_MapMain` 是统一的地图场景，承载背景图、岛屿、路线和箭头。一个 `ScaleTransform` 与一个 `TranslateTransform` 同时作用于整个场景，因此所有世界坐标只需计算一次。

`MapViewportState` 是不依赖 WPF 的纯状态对象，负责缩放锚点换算、平移与范围限制。`MapControl` 只把状态映射到 WPF Transform，并在缩放变化时更新标签的局部字号和测量缓存。标签不使用定时器反复重排；只在内容、高亮状态、缩放等级或地图尺寸改变时重算。

## 视觉与交互

- 路线使用实色细线加方向箭头，并在每个抵达岛屿旁显示圆形步骤编号；不再依赖单一粗虚线作为主要路线信息。
- 路线颜色继续沿用现有路线色；未选中路线使用相同颜色的低透明度版本，选中路线提高线宽、饱和度和箭头可见度。
- 标签的本地字体按 `targetScreenFont / viewportScale` 设置，其中 `targetScreenFont` 在 11–16 DIP 内按平方根曲线变化；场景变换后得到温和的屏幕字号变化。
- 标签信息保持默认可见，缩小时不主动隐藏物品文字或图标。

## 非目标

- 不引入 Web 地图、GIS、瓦片服务或 SVG 渲染器。
- 不改变现有规划算法、仓库逻辑、航行走廊距离计算或路线持久化格式。
- 不修改中键岛屿交换操作。

## 验收标准

1. 鼠标滚轮在岛屿上缩放时，该岛屿保持在指针下方。
2. 右键拖动空白海域能平移地图，且不会触发岛屿操作。
3. 复位后缩放为 100%、平移为零。
4. 任意缩放下，岛屿、航线端点、箭头和编号保持相对对齐。
5. 标签屏幕字号处于 11–16 DIP，选中路线仍易读，未选路线仍可辨认。
6. 中键添加岛屿、船舱步骤选择、路线下拉切换与地图高亮继续工作。
